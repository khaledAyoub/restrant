# 🍽️ Mocha Restaurant – UI Website

A modern and responsive restaurant website UI built using **HTML, CSS, and JavaScript**.  
This project focuses on clean layout structure, visual hierarchy, and front-end design fundamentals.

The goal of this project was to practice building a realistic restaurant landing page with proper sectioning, responsive behavior, and smooth user experience.

---

## 🚀 Features

- Fully responsive design
- Modern hero section
- Food menu showcase
- About section
- Contact section
- Smooth navigation experience
- Clean and organized UI structure
